[Contract index](../README.md) · generated by `backend/cmd/contractdocs`; do not edit.

This is registry evidence, not a complete OpenAPI specification. Routes are mounted without executing handlers. All workflow/dispatch registration gates are enabled with a disconnected client so conditional consumers are included; this does not assert deployment enablement. Permissions do not replace domain object grants. `public` still requires authentication and tenant membership; `no_tenant_membership` still requires authentication. Tenant administrators implicitly receive declared permissions; domain grants remain separate.

Tables below are historical `CREATE TABLE` declarations found in registered migration SQL, not a reconstructed final schema. Read all later migrations for changes and removals. SQL hashes detect migration drift; no database is queried. Functions, policies, views, triggers, indexes and column constraints remain authoritative in the owning migrations.
