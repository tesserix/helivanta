# One look Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The signed-in app and the public pages read one light sage design.
The chrome and the dashboard are simplified, and no native dropdowns remain.

**Architecture:**

- Tokens in `packages/ui/styles.css` become the single palette, and
  `.public-site` reads them.
- Dark mode is deleted outright.
- Modest, enterprise shapes come from Tailwind's `--radius-*` scale (spec D3).
- Each rule is enforced by a unit test or lint rule:
  - contrast;
  - no dark selector;
  - no raw colours;
  - no `<select>`.
- The chrome and dashboard changes are presentational. Data and permission
  gating are untouched.

**Tech Stack:** Next.js 16 (one app, `apps/shell`), Tailwind v4, @tesserix/web,
Vitest + Testing Library, Playwright, ESLint flat config.

**Spec:** `docs/superpowers/specs/2026-10-22-one-look-design.md` (issue #1255).
Supersedes `docs/superpowers/plans/2026-08-11-hms-light-dark-theme.md` (D1).

## Global Constraints

- Light only:
  - no `data-theme="dark"` selector;
  - no `dark:` utility;
  - no theme toggle;
  - nothing reads `hms.theme`.
- Every rendered text/background pair is ≥ 4.5:1, and large text and UI
  component boundaries are ≥ 3:1 (WCAG 2.2 AA).
- Token overrides in `packages/ui/styles.css` keep `!important` (frontend.md
  §7 pitfall 1), and colour values are opaque hex.
- Blue and indigo `data-brand-theme` values are unchanged. Teal moves to the
  sage primary.
- `--hms-good`, `--hms-warn` and `--hms-crit` keep their hue family and are
  darkened only to pass AA.
- Dashboard data, queries and `can(...)` gating are unchanged. Caveat text is
  moved, never edited.
- Dropdowns: `SelectControl` or `FormSelectField` from `@helivanta/ui` only.
- The CSP stays as it is:
  - no new inline script or style;
  - removing `THEME_INIT_SCRIPT` removes a nonce'd script, which is allowed.
- Gates: `pnpm turbo lint type-check test build format:check` and
  `make lint-shell`. Use Node v24.21.0 and the two `NEXT_PUBLIC_ZITADEL_*`
  variables for builds.

## Review Focus

1. **A stored `hms.theme=dark` from before this change.** The page must paint
   light, with no flash. Covered by Task 1: the layout test asserts no theme
   script is emitted, and Task 7's visual proof presets the key.
2. **Tenant brand theme on the new canvas.** Blue and indigo primaries must
   pass AA with white text, and their accent must pass on `#fbfcfa`. Covered
   by Task 2's contrast test.
3. **Status colours on the tinted card regions** (`--muted`), not only on
   white. Covered by Task 2's pair list.
4. **A single-page zone deep link with the panel stored "closed".**
   `CHROME_INIT_SCRIPT` must not leave a gap, since the panel no longer
   renders. Covered by Task 4's single-page test.
5. **The `/ambulance` country picker by keyboard at mobile width.** Enter
   opens it, the arrows move, and the dial link updates. Covered by Task 6's
   unit test and `emergency-access.spec.ts`.
