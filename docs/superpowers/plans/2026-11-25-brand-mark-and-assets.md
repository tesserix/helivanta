# Brand mark and asset set Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the h-with-pulse mark everywhere Helivanta shows itself: the rail, the sign-in fallback, the public nav, the browser tab, the home-screen icon and the link preview. Every one of these comes from `brand/generate.mjs`, and CI fails if any file is stale.

**Architecture:** The generator writes the files that ship (`apps/shell/app/*`, `apps/shell/public/*`, `packages/ui/src/brand-mark.generated.tsx`) and gains a `--check` mode. The UI renders the generated `HelivantaMark` in place of the Lucide heart. The middleware lets the new asset paths through without a session, and the layout gains `metadataBase`.

**Tech Stack:** Node ESM, sharp (from the pnpm store), Next 16 metadata file conventions, React and Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-24-brand-mark-and-assets-design.md` (#1835)

## Global Constraints

- Tokens: ink `#0b1324`, accent `#2b4ee6`, on ink `#7aa0ff`, canvas `#f6f8fb`. The product hues are the #1834 chart tokens. The only new token is `--hms-accent-on-ink: #7aa0ff` (spec D6).
- No raster is used as a source, no font is embedded, and no hand-written `<link>` tag is added. The Next file conventions do the wiring (D6).
- The mark appears alone in the rail, the favicon and the app icon. It appears with the word in the sign-in header and the public nav (D4).
- The manifest uses `display: "browser"` and `start_url: "/"` (D6).
- `csp.ts` does not change, and the whole asset set stays under 200 KB (D8).
- The CI rule (AGENTS.md): no local builds or e2e. Vitest, lint, type-check and the generator run locally.

## Review Focus

1. **The pixel check across platforms.** The committed PNGs come from macOS and CI runs Linux. The check compares decoded pixels. If CI fails on pixels alone, the tolerance becomes a ledgered ruling, never a silent widening. Covered by the first green web job.
2. **A tenant with a theme and no logo.** The fallback mark's pulse follows `--hms-accent`, so it is correct under teal, blue or indigo. Pinned in Task 2 by asserting that the pulse stroke is `var(--hms-accent)`, not a hex value.
3. **A signed-out fetch of the manifest or an icon.** It must get 200, not a 307 to `/login`. Similarly named paths stay private. Pinned in Task 4 (middleware test) and by the e2e request check.
4. **The mark on ink.** The rail and the split sign-in panel must use white bars and the `#7aa0ff` pulse. Pinned in Task 2 by asserting the `onInk` stroke variable, and by the contrast test pair.
5. **The link preview URL.** `og:image` must be absolute on `https://helivanta.app`. Pinned in Task 4 by the e2e meta assertion.

**Interfaces:**

- Produces: CLI `node brand/generate.mjs <sharp-path> [--check]`, with the repo root resolved from `import.meta.url`. It exits 1 and prints `stale: <repo-relative path>` for each file that differs.
- Produces: `packages/ui/src/brand-mark.generated.tsx` exporting `HelivantaMark({ onInk?: boolean; className?: string })`. It renders `<svg viewBox="0 0 64 64" aria-hidden="true">` with both rects `fill="currentColor"` and the path stroke `var(--hms-accent)`, or `var(--hms-accent-on-ink)` when `onInk` is set. The file starts with a `// Generated by brand/generate.mjs (#1835). Do not edit.` header and must already be clean under prettier and eslint.

  - `.png`: sharp `raw()` pixels and dimensions;
  - `.ico`: by its embedded PNGs.
- [ ] Run it in write mode, then `pnpm exec prettier --check packages/ui/src/brand-mark.generated.tsx`. Expected: clean.
- [ ] Run `--check`. Expected: exit 0.
- [ ] RED proof: change `PRODUCTS.lab` by one digit and run `--check`. Expected: exit 1, naming `brand/svg/mark-lab.svg` and the lab PNGs. Revert, and ledger the output.
